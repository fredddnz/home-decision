# Home Decision

An interactive Auckland home decision preview with an English interface.

Website: https://fredddnz.github.io/home-decision/

This repository contains only the public frontend. The Cloudflare backend keeps project records isolated by a browser capability. Existing projects do not sync across browsers or devices. Readable PDFs and text extracts are supported; scanned PDF OCR is unavailable online.

Purchase support is a provisional weighted utility, not a probability of investment success or professional clearance. Evidence completeness measures collected checklist items. Open the existing metric and area details to inspect sources, assumptions and missing information.

See THIRD_PARTY_NOTICES.md for bundled asset notices.

Release 0.15 adds native Bayesian structural/moisture follow-up scenarios from eligible report and firsthand viewing evidence. Existing read-only details disclose the prior, likelihood ratio, selected/excluded evidence and sensitivity. Parameters are uncalibrated engineering assumptions, not measured defect probabilities. Repeated evidence is treated as correlated; material review holds still override purchase support. The main English interface is unchanged.

Release 0.16 adds native seeded Monte Carlo economic scenarios in the existing read-only support, Finance and Market details. It propagates explicitly assumed mortgage rates, recurring ownership costs and market-reference changes through the decision equations, with separate independent/adverse-linked cases, all-draw versus conditional supported statistics and denominators. These are uncalibrated scenarios, not economic forecasts or a probability of buying success. The baseline support and main English layout are unchanged.

Release 0.17 preserves confirmed blank PDF pages and their original page numbers. Page inspection distinguishes native text, substantial scans and mixed documents. When a page needs OCR, the online frontend stops before uploading the original file or accepting partial evidence; the backend also rejects binary PDFs. Small embedded images carry an extraction limitation. Scanned OCR remains unavailable online. The main English layout and 0.16 decision equations are unchanged.
